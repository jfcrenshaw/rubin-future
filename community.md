Rubin Future is intended to be a hub for the community-led Rubin Future planning effort. 

## How to Participate

If you participated in the Rubin 2036 workshop, follow the instructions [here]("/pages/Rubin2036proceedings/") to add your science case document.
If you did not participate but want to add a science case document, please make an issue on the GitHub repository for this site.

## Code of Conduct

The Rubin Future effort adheres to the [Rubin Observatory Code of Conduct](https://rubinobservatory.org/for-scientists/code-of-conduct).

## Contact

To reach the organizers, please make an issue on the GitHub repository for this site.
